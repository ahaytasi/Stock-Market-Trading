This repository hosts the source code and production files for the Stock Trading System for IFT 401, a responsive web-based financial market dashboard and trading simulator. Built using modern file uploads such as index.html, styles.css and app.js, provides users with real-time market overviews, interactive asset performance charts, simulated order execution against a cash balance, and a complete transaction and portfolio tracking ledger.

The authors are Alexandra Haytasingh, Ethan Boyd and Ryan Phillips.
